# LNG Shipping Optimization

## Overview

This project explores mathematical optimization methods for LNG shipping
and maritime logistics.

The objective is to develop optimization models and algorithms for
planning LNG transportation operations under operational constraints.

The project focuses on mathematical programming, heuristic algorithms,
and stochastic optimization.

## Methods

- Mixed-Integer Linear Programming (MILP)
- Variable Neighborhood Search (VNS)
- Hybrid optimization heuristics
- Stochastic programming
- Scenario-based decision-making

## Problem Description

The LNG shipping problem involves coordinating vessels, cargoes, and
transportation schedules while respecting operational constraints.

The optimization framework aims to identify feasible and economically
efficient shipping plans.

Potential constraints include:

- Vessel availability and capacity
- Cargo delivery requirements
- Loading and delivery time windows
- Vessel routing and scheduling
- Operational and compatibility constraints

The exact formulation and assumptions will be documented as the
implementation develops.
